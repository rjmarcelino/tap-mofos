Bulk create from a spreadsheet

Make many cards at once. Everything is saved in a single commit, so the site rebuilds only once. Fill it in with Excel or Google Sheets and save as CSV. One row per card. Only name is required. Social columns accept a handle (janedoe) or a full link. Select all the images at once. Each is matched by file name to the photo or logo column, or to the slug (jane.jpg for slug jane).

Settings

These are stored only in this browser. They tell the builder which GitHub repo to save your pages to. The token needs access to this repo only, with Contents set to Read and write. Used for the saved link, QR codes, and share previews. Leave empty to use the address this admin page is opened from.
